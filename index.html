How to write predecessors

Type the ID of the task that must come first. Separate several with commas.
3 = task 3 must finish before this starts (Finish-to-Start)
3SS = start together · 3FF = finish together · 3SF = start-to-finish
3FS+2 = 2 working days after task 3 finishes · 4SS+1w = 1 week after task 4 starts · 5FS-1 = overlap by 1 day
Successors fill in automatically. Use the ⇥ / ⇤ buttons to make phases (summary tasks).
